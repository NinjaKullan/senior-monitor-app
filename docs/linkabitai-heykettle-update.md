# linkabitai.com update: add HeyKettle

## Why this update matters (context for the coding agent)

Meta/WhatsApp rejected the display name "HeyKettle" for our WhatsApp Business
account because the website on file for the business (linkabitai.com) never
mentions HeyKettle. Meta's reviewers need to see a clear, public connection
between the legal entity (LINKABIT AI LABS LLC) and the brand name.

Three things are therefore NON-NEGOTIABLE in this update:

1. The exact string **HeyKettle** — capital H, capital K, one word. Never
   "heykettle", "Heykettle", or "Hey Kettle".
2. A working link to **https://heykettle.com/**.
3. An explicit statement that HeyKettle is a product/service of
   **LINKABIT AI LABS LLC** (exact legal name, all caps as shown).

The copy below is final. Please use it verbatim — the wording has been
checked against the product's messaging rules, so do not paraphrase,
"improve", or extend it. Layout/styling should simply match the existing
site components.
