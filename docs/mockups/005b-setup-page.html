Teach your phone when to use them

Two automations. One paragraph each — the pictures do the work.

  1. 1In Shortcuts, tap Automation → + → App. Pick all the apps you open every day (WhatsApp, YouTube…). Choose Is Opened and Run Immediately → pick Kettle — Daily routine.
  2. 2Again: + → Charger. Tick both "Is Connected" and "Is Disconnected". Choose Run Immediately → pick Kettle — Charger.
